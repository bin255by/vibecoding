## HTML常见标签总结

### 标题标签

- `<h1>` 到 `<h6>`：这些标签用于定义HTML文档的标题。`<h1>` 表示最高级别的标题，而 `<h6>` 表示最低级别的标题。标题标签不仅有助于页面内容的组织，还对搜索引擎优化（SEO）至关重要。

### 段落和文本格式化

- `<p>`：定义段落，是文本的基本块元素。

- `<br>`：插入一个换行符，用于在不开始新段落的情况下换行。

- `<strong>` 或 `<b>`：使文本加粗，用于强调内容。

- `<em>` 或 `<i>`：使文本倾斜，用于强调内容。

- `<del>` 或 `<s>`：在文本上添加删除线，表示内容不再相关或准确。

- `<ins>` 或 `<u>`：在文本下添加下划线，表示新添加的内容。

### 容器标签

- `<div>`：块级容器，用于组织内容和布局。

- `<span>`：[^行内容器]，用于组织文本或应用样式。

### 图像和超链接

- `<img>`：嵌入图像，必须包含 `src`（图像的路径）和 `alt`（替代文本）属性。

- `<a>`：定义超链接，可以链接到另一个页面、文件、邮箱地址或页面内的某个部分。`href` 属性指定链接的目标，而 `target` 属性定义如何打开链接（例如，在新窗口中打开）。

### 列表

- `<ul>`：定义无序列表。

- `<ol>`：定义有序列表。

- `<li>`：定义列表项。

- `<dl>`、`<dt>`、`<dd>`：定义描述列表，其中 `<dt>` 用于项目名称，`<dd>` 用于描述。

### 表格

- `<table>`：定义表格。

- `<tr>`：定义表格行。

- `<td>`：定义标准单元格。

- `<th>`：定义表头单元格，通常加粗和居中显示。

- `<thead>`、`<tbody>`、`<tfoot>`：分别定义表格的头部、主体和脚部。

### 表单

- `<form>`：创建一个表单，用于收集用户输入。

- `<input>`：定义输入字段，type 属性指定不同类型的输入，如文本、密码、提交按钮等。

- `<textarea>`：定义多行文本输入。

- `<label>`：定义输入字段的标签，通常与 input 元素一起使用。

- `<select>` 和 `<option>`：定义下拉列表和选项。

### 语义化和结构化

- `<header>`、`<footer>`、`<section>`、`<article>`、`<aside>`、`<nav>`、`<main>`：这些标签定义文档或文档部分的结构，有助于构建更具语义化的页面。

了解和正确使用这些HTML标签对于创建结构良好、语义清晰的网页至关重要。此外，合理使用这些标签还可以提高网站的可访问性和搜索引擎排名。

## 绝对定位与相对定位的区别

在CSS中，绝对定位（`position: absolute;`）和相对定位（`position: relative;`）是两种常用的定位方式，它们在页面布局中扮演着重要的角色。理解它们的区别对于掌握CSS布局至关重要。

### 绝对定位（Absolute Positioning）

绝对定位的元素会从文档流中脱离，不再占据原来的空间。它会相对于最近的已定位的祖先元素进行定位。如果没有已定位的祖先元素，则相对于文档的`<body>`元素。绝对定位的元素可以通过`top`、`right`、`bottom`和left属性在任何位置精确放置，而且它不会影响其他元素的布局。例如，如果你想让一个元素位于页面的右下角，你可以这样设置：

```
element {  
position: absolute;  
right: 0;  
bottom: 0;  
}
```

## 相对定位（Relative Positioning）

相对定位的元素仍然保留在文档流中，即它仍然占据原来的空间。当你对一个元素应用相对定位时，你可以通过`top`、`right`、`bottom`和`left`属性来移动它，但它原来的位置仍然被保留，就像元素还在那里一样。这意味着相对定位不会影响周围元素的布局。例如，如果你想将一个元素向下移动20像素，你可以这样设置：

```
element {  
position: relative;  
top: 20px;  
}
```

关键区别

- **文档流影响**：绝对定位的元素会脱-离文档流，而相对定位的元素不会。

- **定位上下文**：绝对定位是相对于最近的非`static`定位的祖先元素，而相对定位是相对于元素自身的原始位置。

- **布局影响**：绝对定位可能会影响其他元素的布局，因为它脱离了文档流。相对定位则不会影响其他元素的布局。

在实际应用中，绝对定位常用于创建覆盖在其他元素上的组件，如模态框或下拉菜单。相对定位则常用于对元素进行微调，而不影响周围元素的布局。

理解这些概念对于创建响应式和灵活的网页布局非常重要。通过恰当地使用绝对定位和相对定位，可以实现各种复杂的布局效果，从而提升用户界面的整体体验

## 块级元素和行内元素的区别

**块级元素独占一行，可设置宽高并包含其他元素；行内元素不独占一行，仅占内容所需空间，不能设置宽高。**
### 定义与布局特性

#### 块级元素（Block-level elements）：

- 每个元素独占一行，默认宽度为父容器的100%。 

- 可以设置宽度（width）、高度（height）、上下左右外边距（margin）和内边距（padding）。 

- 可以包含行内元素和其他块级元素。 

- 常见标签：`<div>`、`<p>`、`<h1>`~`<h6>`、`<ul>`、`<ol>`、`<li>`、`<table>`等。 

#### 行内元素（Inline elements）：
- 不独占一行，多个行内元素可以在同一行排列，直到一行排不下才换行。 

- 宽度和高度由内容决定，设置 `width`、`height`、`margin-top`、`margin-bottom`、`padding-top`、`padding-bottom` 无效。

- 只能包含文本或其他行内元素，不能包含块级元素。

- 常见标签：`<span>`、`<a>`、`<strong>`、`<em>`、`<b>`、`<i>`、`<img>`、`<input>` 等。 

#### 行内块元素（Inline-block elements）

- 结合了块级元素和行内元素的特性：可以在一行内显示，同时支持设置宽高和上下左右外边距。 

- 常见标签：`<img>`、`<input>`、`<button>`、`<textarea>` 等。 

#### CSS转换方法
- 将块级元素转换为行内元素：`display: inline;`

- 将行内元素转换为块级元素：`display: block;`

- 将行内元素转换为行内块元素：`display: inline-block;`

总结
| 特性 | 块级元素 | 行内元素 | 行内块元素 |
|------|----------|----------|------------|
| 是否独占一行 | 是 | 否 | 否 |
| 可设置宽高 | 是 | 否 | 是 |
| 可设置上下外边距 | 是 | 否 | 是 |
| 可包含元素类型 | 块级+行内 | 仅行内 | 块级+行内 |
| 常见标签 | `<div>`、`<p>`、`<h1>`~`<h6>` | `<span>`、`<a>`、`<strong>` | `<img>`、`<input>`、`<button>` |

通过理解这些区别，开发者可以更合理地布局网页结构，控制元素样式和排列方式。

## css的盒子模型
CSS盒子模型是CSS中的基本概念，它描述了如何围绕HTML元素布局各种元素。盒子模型包括四个部分：`内容(content)`、`内边距(padding)`、`边框(border)`和`外边距(margin)`。

### 盒子模型的组成

- **内容(content)**: 这是盒子的中心部分，用于显示文本、图片或其他内容。

- **内边距(padding)**: 内边距位于内容区域的外围，可以增加内容与边框之间的空白区域。

- **边框(border)**: 边框环绕在内边距的外围，可以为盒子添加边线。

- **外边距(margin)**: 外边距是盒子最外层的空间，用于控制盒子与其他元素之间的距离。

### 盒子模型的类型

CSS中有两种盒子模型：

- **标准盒子模型**: 在这个模型中，元素的`width`和`height`属性只包括`内容(content)`区域，不包括`内边距(padding)`和`边框(border)`。

- **IE盒子模型(怪异盒子模型)**: 在这个模型中，元素的`width`和`height`属性包括`内容(content)`、`内边距(padding)`和`边框(border)`。

## var、let 和 const 的区别和用法

在 JavaScript 中，`var`、`let` 和 `const` 是三种用于声明变量的关键字。它们在作用域、变量提升和可变性方面存在显著差异。

### var 的特点

- **变量提升**：var 声明的变量会被提升到其作用域的顶部，但初始化(赋值)保留在原地,因此,var变量在生命前使用会返回为 `undefined`。

```
console.log(a); // undefined  
var a = 10;  
```

- **作用域**：var 的作用域是**函数作用域**，在函数内部声明的变量仅在函数内有效;在函数外部声明的变量是全局作用域。

```
if (true) {
var a = 10;
}
console.log(a); // 10
```

- **重复声明**：var 允许在同一作用域内重复声明变量。

```
var a = 10;
var a = 20;
console.log(a); // 20
```

### let 的特点

- **无变量提升**：`let` 声明的变量不会被提升，在声明之前使用会导致 `ReferenceError`。

```
console.log(a); // ReferenceError: a is not defined
let a = 10;
```
- **作用域**：let 的作用域是块级作用域，即它只在定义它的块级作用域内有效。

```
if (true) {
let a = 10;
}
console.log(a); // ReferenceError: a is not defined
```

- **不允许重复声明**：let 不允许在同一作用域内重复声明变量。

```
let a = 10;
let a = 20; // SyntaxError: Identifier 'a' has already been declared
```

### const 的特点

- **只读变量**：`const` 声明一个只读的变量，声明后其值不能改变。

```
const a = 10;
a = 20; // TypeError: Assignment to constant variable
```

- **必须初始化**：const 声明时必须进行初始化。

```
const a; // SyntaxError: Missing initializer in const declaration
const a = 10; // OK
```

- **块级作用域**：`const` 具有块级作用域，与 `let` 类似。

```
if (true) {
const a = 10;
}
console.log(a); // ReferenceError: a is not defined
```

### 使用建议

在实际开发中，建议尽量使用 const，其次是 let，避免使用 var。const 可以确保变量不会被意外修改，而 let 则提供了更清晰的作用域规则。
